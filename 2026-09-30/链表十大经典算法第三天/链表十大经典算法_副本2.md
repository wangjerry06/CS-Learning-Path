## 第 1 题 · 反转链表（LC 206）Easy

**题目**：给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例**：

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

**进阶要求**：链表可以选用迭代或递归两种方式完成。两种都要会写——递归版是理解「回溯时指针怎么掉头」的好素材。

**约束**：节点数范围 `[0, 5000]`；要求 O(n) 时间。空间上迭代版必须 O(1)。

<details>
<summary>提示（卡住超过 15 分钟再看）</summary>

三个指针 `prev / cur / next`，口诀：**先备份，再掉头，双前进**。断链之前必须先存 `cur->next`，否则后路永失。

</details>

## 第 2 题 · 链表的中间结点（LC 876）Easy

**题目**：给定单链表的头节点 `head`，返回中间结点。如果有两个中间结点，则返回第二个中间结点。

**示例**：

```
输入：head = [1,2,3,4,5]   输出：节点 3
输入：head = [1,2,3,4,5,6] 输出：节点 4
```

**进阶要求**：只允许**一次遍历**（不许先数长度再走一半）。

**约束**：节点数范围 `[1, 100]`。

<details>
<summary>提示</summary>

龟兔赛跑：快指针一次走 2 步，慢指针一次走 1 步。快指针到终点时，慢指针正好在中间。注意偶数长度时返回的是**第二个**中点，循环条件里 `fast` 的判断顺序很讲究。

</details>

## 第 3 题 · 环形链表（LC 141）Easy

**题目**：给你一个链表的头节点 `head`，判断链表中是否有环。如果链表中存在某个节点，可以通过连续跟踪 `next` 指针再次到达它，则链表中存在环。

**示例**：

```
输入：head = [3,2,0,-4]，pos = 1（尾节点连接到索引 1 的节点）→ 输出：true
输入：head = [1,2]，pos = 0 → 输出：true
输入：head = [1]，pos = -1 → 输出：false
```

**进阶要求**：能用 O(1) 空间解决吗？（哈希表法是 O(n) 空间，先用它写对，再挑战 O(1)。）

<details>
<summary>提示</summary>

Floyd 判圈：快一次 2 步、慢一次 1 步。相对速度是 1，所以快者每轮逼近 1 格，**不存在跳过**——只要进了环必相遇。没环则快指针先碰到 `nullptr`。

</details>

## 第 4 题 · 环形链表 II · 找环的入口（LC 142）Medium

**题目**：给定链表头节点 `head`，返回链表**开始入环的第一个节点**。如果无环，返回 `nullptr`。不允许修改链表。

**示例**：

```
输入：head = [3,2,0,-4]，pos = 1 → 输出：入环节点（值为 2 的节点）
输入：head = [1]，pos = -1 → 输出：nullptr
```

**进阶要求**：O(1) 空间。这题的真正考点是**证明**——把推导写在注释里。

**约束**：节点数范围 `[0, 10⁴]`。

<details>
<summary>提示</summary>

设头到入口为 `a`，入口到相遇点为 `b`，环剩余部分为 `c`。相遇时慢指针走 `a+b`，快指针走 `a+b+n(b+c)`，由「快是慢的 2 倍」推出 `a = c + (n-1)(b+c)`。结论：**相遇后把一个指针放回起点，两指针同速前进，再次相遇处就是入口**。

</details>

## 第 5 题 · 合并两个有序链表（LC 21）Easy

**题目**：将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**示例**：

```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**进阶要求**：体会**哨兵节点（dummy node）**的威力——不设哨兵的话，头节点选谁需要特判；设了哨兵，所有节点一视同仁。这是第 6、7 题的地基。

<details>
<summary>提示</summary>

`dummy` 挂在结果链表前，`tail` 指针负责拼接，每次摘下 `l1/l2` 中较小的那个。最后把没比完的一条直接整体接上。返回 `dummy->next`。

</details>

## 第 6 题 · 合并 K 个升序链表（LC 23）Hard

**题目**：给你一个链表数组，每个链表都已按升序排列。请你将所有链表合并到一个升序链表中，返回合并后的链表。

**示例**：

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
```

**约束**：`k` 个链表，每个最多 `n` 个节点。要求写出优于「逐条两两合并」的做法。

**通关标准**：这题至少掌握**两种**解法——

1. **小顶堆**：维护 k 个候选头节点，每次弹出最小的。O(N log k)
2. **分治**：两两配对合并，像锦标赛一样打淘汰赛。同样 O(N log k)，但不用堆

对比一下两两顺序合并为什么是 O(Nk)，搞清楚 log k 省在了哪。

<details>
<summary>提示</summary>

分治法就是第 5 题当零件：`merge(lists[i], lists[i+k/2])`，递归折半。堆法用 C++ 的 `priority_queue` + 自定义比较器（注意比较器方向和 sort 相反，经典翻车点）。

</details>

## 第 7 题 · 删除链表的倒数第 N 个结点（LC 19）Medium

**题目**：给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。要求**一趟扫描**实现。

**示例**：

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**进阶要求**：一趟扫描 + O(1) 空间。

**约束**：节点数范围 `[1, 30]`；试试不加以任何特判，删掉头节点（`head = [1], n = 1`）时也能过。

<details>
<summary>提示</summary>

双指针保持固定距离 `n`：快指针先走 n 步，然后快慢同步走，快指针到尾时慢指针正停在**待删节点的前一个**。用哨兵节点可以消灭「删头」这个特判——本题和第 5 题是哨兵内功的两次实战。

</details>

## 第 8 题 · 相交链表（LC 160）Easy

**题目**：给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表**相交的起始节点**。如果不存在相交节点，返回 `nullptr`。整个链式结构中**不存在环**。要求 O(1) 内存，函数返回后原链表必须保持原状。

**示例**：

```
headA = [4,1,8,4,5]，headB = [5,6,1,8,4,5]，从值为 8 的节点开始相交
```

**核心思想（这题考的是洞察力，不是代码量）**：

两个指针各自从自己链表的头出发，走到头就**换到另一条链表的头**继续走。如果相交，两条路长度相等（`a+c` 与 `b+c`），必然在交点相遇；不相交则同时到达 `nullptr`。 eliminate 差值的机制极其优雅，建议手推一遍证明。

<details>
<summary>提示</summary>

指针 pA 走的路：`a + c + b`；指针 pB 走的路：`b + c + a`。长度相同 → 步调一致 → 交点必然同步踩到。最多走 `a+b+c` 步，复杂度 O(a+b)。

</details>

## 第 9 题 · 回文链表（LC 234）Easy

**题目**：给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。要求 O(n) 时间、O(1) 空间。

**示例**：

```
输入：head = [1,2,2,1] → 输出：true
输入：head = [1,2]     → 输出：false
```

**通关标准**：这题是「内功合璧」——先用第 2 题的快慢指针找中点，再用第 1 题的原地反转处理后半段，最后逐个比对。做完这题你会体会到：前面的每一式都不是白练的。

**约束**：节点数范围 `[1, 10⁵]`（数组/栈法空间不达标，只能当对拍用）。

<details>
<summary>提示</summary>

反转后半段后记得**恢复原链表**再返回结果（工程素养 + 题目要求内存不改）。奇数长度时中点节点不参与比对。

</details>

## 第 10 题 · K 个一组翻转链表（LC 25）Hard

**题目**：给你链表的头节点 `head`，每 `k` 个节点一组进行翻转，请你返回修改后的链表。如果节点总数不是 `k` 的整数倍，那么最后剩余的节点保持原有顺序。**只能使用常数额外空间**，且不允许只改节点内部的值，需要实际进行节点交换。

**示例**：

```
输入：head = [1,2,3,4,5], k = 2 → 输出：[2,1,4,3,5]
输入：head = [1,2,3,4,5], k = 3 → 输出：[3,2,1,4,5]
```

**通关标准**：十式大考。它把第 1 题（反转）、第 5 题（哨兵思想）、区间指针管理全部揉在一起，字节跳动高频面试题。能在不看任何资料的情况下一次写对，链表这门功就算出师了。

<details>
<summary>提示</summary>

流程：每组开始前先用指针探测本组是否凑够 k 个 → 记下组头和组尾 → 反转这一段 → 把前一段的尾巴接新头、本组尾巴接下一组。每一步接缝处都要画图确认，最容易错的就是**四条接缝**（前一组的尾、新组头、新组尾、下一组头）。

</details>
